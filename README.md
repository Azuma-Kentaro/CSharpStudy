# About this repository

このリポジトリは「基礎からしっかり学ぶC#の教科書 第4版」の学習記録に関するものです。
単に本の内容をコピーするだけではなく、1つにまとめられる内容はまとめたり、
気になった内容があれば追加で調べたりした内容を加えてあります。

## 全体的な感想

`.NET`の仕組みを利用することで、
`C#`以外の言語で作成した過去の資産を活かせるという強みと、
いわゆる「モダン」なプログラミング言語としての機能を取り入れている感じを受けました。

組織内開発においてはVisual Basicなどの既存の資産を活用しつつ
モダンなプログラミング言語による生産性向上という恩恵を受けられるかもしれません。

しかし、私が個人開発で使う分にはそもそも過去の資産は持っていませんし、
他人の資産を使うのであれば他の言語にも公開リポジトリは存在します。
(PythonのPyPIやRustのCrate.IOなど。)

モダンなプログラミング言語になるために急ピッチで変更を多く加えているので、
バージョン間の互換によるトラブルも多いかと予想します。
(開発現場で使えるのが古いバージョンであるがゆえにモダンな機能を使用できないなど。)

そうした状況であれば最近作られたモダンなプログラミング言語を使ったほうが余計なトラブルにも悩まされないし、
洗練された状況からスタートすることができます。

Unityによる開発ではC#が必須なのでそうした目的で学ぶ価値はありますが、
かつてはJavaでやっていたようなシステム開発で使うために今から学ぼうとは思いません。
