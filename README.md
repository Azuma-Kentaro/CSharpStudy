# About this repository

このリポジトリは「基礎からしっかり学ぶC#の教科書 第4版」の学習記録に関するものです。
単に本の内容をコピーするだけではなく、1つにまとめられる内容はまとめたり、
気になった内容があれば追加で調べたりした内容を加えてあります。

## 全体的な感想

`.NET`の仕組みを利用することで、`C#`以外の言語で作成した過去の資産を活かせるという強みがある。
それに加えてさらに、「モダン」なプログラミング言語としての機能を取り入れている感じを受けました。

組織内開発においてはVB.NETなどの既存の資産を活用できるだけでなく、
モダンなプログラミング言語による生産性向上という恩恵を受けられるかもしれません。

しかし、モダンなプログラミング言語になるために急ピッチで変更を多く加えているので、
バージョン間の互換によるトラブルも多いかと予想します。
(開発現場で使えるのが古いバージョンであるがゆえにモダンな機能を使用できないなど。)

Unityによる開発ではC#が使えたほうができることが増えるので、そうした目的で学ぶ価値はあります。
